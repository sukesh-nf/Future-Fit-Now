FUTUREFITNOW WEBSITE
====================

This is a static website ready for Netlify.
No coding or build step is required.

EASIEST NETLIFY DEPLOYMENT
1. Sign in to Netlify.
2. Use Netlify's drag-and-drop/manual deployment option.
3. Drag the entire "futurefitnow-website" folder into Netlify.
   If Netlify asks for a folder rather than a ZIP, unzip this package first.
4. Netlify will publish the site and give you a temporary *.netlify.app address.
5. Check the website on desktop and mobile.
6. In Netlify, add the existing custom domain: futurefitnow.nz
7. Use the DNS values Netlify provides to update the domain records.

IMPORTANT
- Do not change MX/email DNS records when connecting the website domain.
- The website requires no paid hosting plan for normal small-site use, subject to Netlify's current free-plan limits.
